# OTAKU YEAR-END RAVE 2026 サイト

静的サイト（HTML / CSS / JS + anime.js）。GitHub Pages で公開しています。
https://bellis1120-prog.github.io/otaku-rave-2026/

## ページ
- `index.html` … トップ（概要・ビンゴ説明・景品・タイムテーブル・開催概要・申込・参加者一覧・FAQ）
- `access.html` … 会場アクセス（Google マップ埋め込み）
- `bingo.html` … Web ビンゴカード（参加者が自分で曲を書き込んで作成）

## 情報の更新
表示内容はすべて `js/config.js` で管理しています。

- `formUrl` / `formEmbedUrl` … Google フォームの共有 URL / 埋め込み URL
- `capacity` / `deadline` / `contact` … 定員・締切・連絡先
- `schedule` … タイムテーブル
- `songsPerPerson` … 1人あたりの申請曲数（フォームの設問数に合わせる）
- `sheetCsvUrl` … 参加者一覧の読み込み元（下記）
- `songs` … フォーム以外で受け付けた曲を手動で追加する場合に使用

## 参加申請をサイトに反映する（Google フォーム + スプレッドシート）
GitHub Pages はデータベースを持てないため、Google フォームの回答スプレッドシートを CSV として公開し、サイトが表示のたびに読み込みます。

### 1. フォームを作る
設問は次のとおり（見出しの文字で列を判別するので、言葉を含めてください）。

| 設問 | 必須 | 判別に使う文字 |
|---|---|---|
| ハンドルネーム | ○ | 「名前」または「ハンドル」 |
| 私といえばこの曲（1曲目） | ○ | 「曲」 |
| アーティスト（1曲目） | | 「アーティスト」 |
| 私といえばこの曲（2曲目） / アーティスト（2曲目） | | 同上 |
| 私といえばこの曲（3曲目） / アーティスト（3曲目） | | 同上 |
| ひとことメッセージ | | 「ひとこと」「メッセージ」「コメント」 |

- 曲とアーティストは、1曲目 → 2曲目 → 3曲目の順に並べてください（同じ順番どうしで対応づけます）。
- **メールアドレスの収集はオフ**にしてください。公開したシートは誰でも見られます。

### 2. 回答をスプレッドシートにつなぐ
フォームの「回答」タブ →「スプレッドシートにリンク」で新規作成。

### 3. シートを CSV で公開する
スプレッドシートの「ファイル → 共有 → ウェブに公開」で、
- 公開範囲：回答が入っているシート（「フォームの回答 1」）
- 形式：**カンマ区切り形式（.csv）**

を選んで「公開」。表示された URL を `js/config.js` の `sheetCsvUrl` に貼り付けて push します。

申請はおよそ 5 分以内にサイトへ反映されます（Google 側のキャッシュのため）。
不適切な申請はスプレッドシートの行を削除すれば一覧から消えます。

## ビンゴのルール（実装上の仕様）
- カードは各自がスマホで 24 マスに曲を自由入力して作成（中央は FREE）。申請曲は入力候補に表示されます。
- 同じ曲が複数マスにあるカードは確定できません。
- 確定後は書き換え不可。イベント開始（`start`）前に限り「作り直す」で確定を取り消せます。
- カードは端末のブラウザ（localStorage）に保存されます。当日も同じ端末・ブラウザで開いてください。
- 開いた穴の数（FREE を除く）を大きく表示。ビンゴが出なければ穴の多い順に景品を配布します。
